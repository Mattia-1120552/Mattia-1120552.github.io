# Mattia Warning — Personal Website

Statische Astro-onepager voor het persoonlijke portfolio van Mattia Warning.

## Lokaal starten

```bash
npm install
npm run dev
```

## Productiebuild

```bash
npm run build
npm run preview
```

## GitHub Pages

De configuratie is ingesteld voor:

`https://mattia-1120552.github.io/MattiaWarning.github.io/`

Push naar de `main` branch. Kies daarna in GitHub bij **Settings → Pages → Source** voor **GitHub Actions**.
